# Лабораторная работа 10

## Тема
Изучение процесса создания и конфигурирования виртуальной среды разработки с использованием Vagrant.

## Ход выполнения (macOS Apple Silicon)
В связи с тем, что на архитектуре ARM64 (M-серия процессоров Apple) стандартный провайдер VirtualBox не поддерживает запуск необходимых x86_64 виртуальных машин, работа была адаптирована под нативный провайдер **Docker**.

1. Установлен пакетный менеджер Homebrew, через который развернуты `vagrant` и `docker-cask`.
2. Сконфигурирован `Vagrantfile` с явным указанием провайдера `"docker"` и образа `ubuntu:latest`.
3. Отработаны базовые CLI-команды Vagrant для управления жизненным циклом контейнера в качестве виртуальной среды.
